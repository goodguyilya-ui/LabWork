## 4. UI-компоненты и их состояния

### 4.1. Кнопки (`.btn`)
- **Default:** чистый цвет фона, четкий текст, min-height 44 px для пальца.
- **Hover:** затемнение фона на 10%, плавный переход (`transition: 0.15s`).
- **Focus:** синее кольцо фокуса `box-shadow: 0 0 0 3px rgba(0, 123, 255, 0.4)`.
- **Disabled:** `opacity: 0.55`, `cursor: not-allowed`, блокировка клика.

### 4.2. Поля ввода и выпадающие списки (`.form-control`, `.form-select`)
- **Default:** рамка `#dee2e6`, фон белый / surface, высота 44 px.
- **Hover:** рамка `#adb5bd`.
- **Focus:** подсветка рамки `#007bff`, свечение `box-shadow 0 0 0 3px rgba(0, 123, 255, 0.25)`.
- **Error (`.is-invalid`):** красная рамка `#dc3545`, подсветка `box-shadow 0 0 0 3px rgba(220, 53, 69, 0.25)`.
- **Локальное сообщение об ошибке (`.field-error-msg`):** располагается строго под соответствующим полем, связано атрибутом `aria-describedby`, содержит иконку и понятное объяснение ошибки.

### 4.3. Выпадающие списки выбора (Замена текстовых полей)
- Выбор зала: `<select name="venue_id">` (аудитория, коворкинг, кинозал с указанием мест и цены).
- Выбор оплаты: `<select name="payment_method">` (СБП, очно).

### 4.4. Адаптивные карточки заявок (`.reservation-card`)
- На десктопе формируют удобную сетку 2–3 колонки.
- На мобильном экране 390×844 px выстраиваются в одну вертикальную колонку (без горизонтального скролла!).
- Структура карточки:
  1. **Header:** Номер бронирования (`#101`) + цветной бейдж статуса (`.badge-new`, `.badge-assigned`, `.badge-completed`).
  2. **Title:** Название помещения.
  3. **Body:** Метаданные с иконками (период, способ оплаты, контакты клиента для админа).
  4. **Footer:** Кнопка действия на всю ширину карточки (`.btn-block`).

## 5. Адаптивность под экран 390×844 px (iPhone 12/13/14)

1. **Отсутствие горизонтального переполнения:**
   - Для всех контейнеров задано `box-sizing: border-box`.
   - В `body` установлен `overflow-x: hidden`.
   - Широкие таблицы ЛР2 полностью заменены на карточную верстку (`.cards-grid`).
2. **Touch Targets (эргономика):**
   - Все интерактивные элементы (кнопки, поля ввода, списки) имеют высоту не менее 44 px.
3. **Размер шрифта полей ввода:**
   - 16 px исключает принудительный зум в браузере Safari на iOS при клике на input.
4. **Доступность (A11y):**
   - Поддержка `prefers-reduced-motion` для пользователей с чувствительностью к анимациям.
   - Семантические теги HTML5 (`<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`).
   - `aria-describedby` и `role="alert"` для сообщений валидации.
