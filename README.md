# Система бронирования помещений — ПИРИП (ЛР-02 и ЛР-03)

Полнофункциональное веб-приложение для сервиса бронирования площадок (аудитории, коворкинг, кинозалы) с серверной валидацией, разделением прав (Пользователь / Администратор), карточным адаптивным интерфейсом под экран 390×844 px, библиотекой компонентов (UI-Kit) и тёмной темой.

- **Дисциплина:** Проектирование и разработка интерфейсов пользователя (ПИРИП 2026/2027)
- **ЛР-02:** Backend, база данных PostgreSQL, безопасность, роли, сессии, отзывы.
- **ЛР-03:** Дизайн-токены КИМ, шрифт PT Sans, адаптивная вёрстка под 390×844 px, UI-Kit, inline-ошибки полей, выпадающие списки, тёмная тема.

## 1. Спецификация UI-Kit и токенов КИМ (ЛР-03)

- **Палитра КИМ:**
  - Голубой: `#007bff` (`--color-primary`)
  - Тёмно-синий: `#0d47a1` (`--color-primary-dark`)
  - Серый: `#6c757d` (`--color-secondary`)
  - Фон: `#f8f9fa` (`--color-background`)
  - Выделяющий / карточки: `#ffffff` (`--color-surface`)
- **Типографика:**
  - Семейство шрифтов: `PT Sans` (Google Fonts)
  - `H1`: 36 px (28 px на мобильном)
  - `H2`: 24 px (22 px на мобильном)
  - `H3`: 18 px
  - Основной текст: 16 px
  - Вспомогательный текст: 12 px italic
- **Целевой мобильный экран:** 390×844 px (iPhone 12/13/14). Полное отсутствие горизонтального скролла (`overflow-x: hidden`, карточная сетка вместо широких таблиц).
- **Формы:** выпадающие списки `<select>` для помещений и способа оплаты, вывод сообщений об ошибках непосредственно у соответствующего поля (`aria-describedby`).
- **Интерактивная витрина UI-Kit:** доступна по маршруту `/uikit` и описана в `ui-kit.md`.
- **Тёмная тема:** переключатель с сохранением в `localStorage` и поддержкой `prefers-color-scheme`.

## 3. Быстрый старт

### 1. Подготовка базы данных PostgreSQL

```bash
psql -U postgres -c "CREATE DATABASE venue_db;"
psql -U postgres -d venue_db -f sql/schema.sql
psql -U postgres -d venue_db -f sql/seed.sql
```

### 2. Установка зависимостей Python

```bash
pip install -r requirements.txt
```

### 3. Запуск сервера

```bash
cd src
python app.py
```

Приложение доступно в браузере по адресу: **http://localhost:5000**
